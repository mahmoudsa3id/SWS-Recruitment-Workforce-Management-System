# إعداد حساب HR في SWS

## الصلاحيات
- الدخول إلى قائمة المسافرين وملفاتهم.
- تحديث مراحل قدم/كشف/تأشيرة/طيران.
- عرض وتنزيل المستندات ورفع مستندات جديدة.
- لا توجد واجهات للحسابات أو الخزنة أو المصروفات أو المرتبات أو التقارير الإدارية.
- لا يستطيع HR إضافة/حذف مسافر، أو تعديل بياناته الأساسية، أو تسجيل دفعة، أو حذف مستند.
- لا تُرجع واجهة HR قيم الاتفاق والتحصيل والمتبقي في قائمة المسافرين أو الملف.

## تفعيل التحديث
1. خذ نسخة احتياطية من قاعدة Supabase.
2. طبّق migration `supabase/migrations/202610230002_sws_hr_role.sql` بعد التحديثات السابقة. التحديث إضافي ولا يمسح بيانات المسافرين أو الحركات المالية.
3. أنشئ مستخدمًا بالبريد وكلمة المرور من Supabase Dashboard > Authentication > Users.
4. استبدل `HR_EMAIL_HERE` في SQL التالي بالبريد الفعلي، ثم نفّذه مرة واحدة من SQL Editor:

```sql
insert into public.profiles(user_id, email, full_name, role, is_active)
select id, email, 'موظف الموارد البشرية', 'hr', true
from auth.users
where lower(email) = lower('HR_EMAIL_HERE')
on conflict (user_id) do update
set email = excluded.email, full_name = excluded.full_name, role = 'hr', is_active = true;
```

5. سجّل الدخول من التطبيق بحساب HR واختبر رفع مستند وتغيير مرحلة.

## تنبيه أمان
هذا التحديث يقيّد الوصول عبر Supabase RLS وRPC وليس بإخفاء القوائم فقط. لا تمنح حساب HR دور admin. لا يتم تنفيذ أي SQL تلقائيًا من التطبيق؛ يجب تطبيق ملف الترحيل يدويًا على قاعدة البيانات المقصودة بعد مراجعتها.
