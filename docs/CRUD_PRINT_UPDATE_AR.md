# تحديث التعديل والحذف والطباعة — SWS

## ما تمت إضافته
- المرتبات: قائمة إجراءات لكل استحقاق تشمل تعديل الاستحقاق وحذفه وطباعة كشف الاستحقاق. لا يسمح التطبيق بتعديل/حذف سجل عليه دفعات؛ يجب التعامل مع الدفعات أولًا.
- المصروفات: تعديل التصنيف والبيان والمبلغ وطريقة الدفع، حذف المصروف بتسوية مالية عكسية، وطباعة إيصال المصروف.
- الحركات المالية: تعديل البيان مع سبب، تسوية/مسح الحركة من الواجهة عبر حركة عكسية مسجلة، وطباعة الإيصال لكل حركة.
- مستندات وملفات المسافرين: تظل أدوات التصدير والطباعة والإيصالات الموجودة في ملف المسافر متاحة.
- إضافة Migration باسم `202610180002_sws_full_crud_print.sql`.

## تطبيق الترحيل على قاعدة بيانات قائمة
1. خذ نسخة احتياطية من قاعدة البيانات قبل أي تعديل.
2. افتح Supabase SQL Editor.
3. انسخ محتوى `supabase/migrations/202610180002_sws_full_crud_print.sql` وحده وشغّله.
4. لا تشغّل `INSTALL_ALL_MIGRATIONS.sql` على قاعدة الإنتاج؛ فهو ملف تثبيت كامل وليس ترحيلًا تفاضليًا.

## ملاحظات محاسبية
- تعديل مبلغ/طريقة دفع مصروف لا يكتب فوق الحركة القديمة: ينشئ حركة عكسية ثم حركة مصروف مصححة، ويسجل العملية في `audit_log`.
- حذف المصروف يزيل تفاصيله من قائمة المصروفات ويحتفظ بالحركة الأصلية والعكسية في دفتر الخزنة وسجل التدقيق.
- لا يمكن تعديل أو حذف استحقاق راتب له دفعات مسجلة حتى لا تختلف قيمة المرتب عن حركة الصرف.
- الحركات في شهر مقفول تظل محمية.

## الاختبار
تم تعديل الملفات والمراجعة النصية فقط في بيئة لا تحتوي على Flutter/Dart SDK؛ يلزم تشغيل `flutter pub get` و`flutter analyze` واختبار الترحيل على قاعدة تجريبية قبل الإنتاج.
